# Recon map: Notion Mobile (Android) — 악보 편집 부분

범위: 악보를 고치는 부분(음표 입력, 선택·편집, 도구 격자, 마디 메뉴, 편집 중 재생). 새 악보 만들기·악기 고르기·음원·계정·내보내기는 범위 밖.
대상: 찬양 이지까까의 교정(수정) 화면 — 변환한 악보의 틀린 곳을 휴대폰에서 고치는 사람.
날짜: 2026-10-09
방법: `replica-recon`(github.com/Jakeschincariol/replica-skill). 공개 자료만 읽었다. 원본 앱의 코드·화면 그림·문구는 가져오지 않는다(D-222).

## Core loop

도구를 하나 집고(음표·쉼표·기호) 악보를 누르면 그 자리에 들어간다. 있는 것은 눌러 고르고 끌어서 고친다.

## Flows

```
F01 빈 자리에 음표 넣기
    S01 음표 도구 -> (S02 길이) -> 오선 누르기
    happy path clicks: 2 (길이를 바꾸면 3)
    edge: 길게 눌러 높이 맞추기, 좌우로 끌어 임시표, 쉼표로 넣기

F02 건반으로 한 줄 이어 쓰기(step entry)
    S04 건반 열기 -> step entry 켜기 -> 길이 -> 건반 누르기 … (커서가 스스로 다음으로)
    happy path clicks: 음 하나에 1
    edge: 화음, 쉼표(길이 + 쉼표), 붙임줄(T), 옥타브 이동

F03 틀린 음 하나 고치기
    S01 선택 도구 -> 음 누르기 -> 위아래로 끌기(높이) / 좌우로 끌기(임시표) / 길이 누르기
    happy path clicks: 2
    edge: 쉼표로 바꾸기, 지우개, 이명동음

F04 여러 음에 같은 것 하기
    S01 꾹 눌러 끌어 범위 선택 -> 도구 누르기(스타카토, 셈여림, 길이, 쉼표로…)
    happy path clicks: 2
    edge: 손잡이로 범위 넓히기, 떨어진 음 고르기

F05 마디째로 옮기기
    S01 마디 두 번 누르기 -> S05 복사 -> 다른 마디 누르기 -> 붙여넣기
    happy path clicks: 4
    edge: 박 위치가 다른 곳에 붙여넣기(reflow), 끼워 넣기, 조옮김, 마디 삭제·넣기

F06 기호 붙이기
    S03 도구 격자 -> 도구 -> (하위 선택) -> 음이나 마디 누르기
    happy path clicks: 3
    edge: 이음줄·헤어핀은 눌러 끌기, 선택이 있으면 도구만 눌러도 들어감

F07 고친 곳 들어 보기
    커서 놓기 -> 재생
    happy path clicks: 2
    edge: 선택한 부분만 재생, 되감기 한 번(재생 시작한 곳)·두 번(맨 처음)
```

## Inferred data model

우리 쪽은 MusicXML 문서 그대로가 자료 모델이라 새로 정할 것이 없다(`XmlMeasureEditor`가 문서를 고쳐 새 버전으로 저장, 원본은 건드리지 않음). 원본 앱의 파일 형식(.notion)은 읽지 않았고 필요도 없다.

## Feature matrix

`features.csv` — 127줄(우리 앱에만 있는 것 2줄 제외), skip 6.
점수는 `parity.md`: 처음 조사 64.0 → 구현 뒤 91.0 → 재검토에서 빠뜨린 18줄을 넣고 다른 동작을 고친 뒤 **86.9 / 100**, must 42개 전부 완료.
처음 표는 설명서를 한 번 훑어 만든 것이라 빠진 줄이 있었고, "됨"으로 적은 것 가운데 동작이 설명서와 다른 것이 9가지 있었다(WORK_LOG 2026-10-09 재검토).

## Out of scope (복제할 수 없거나 하지 않는 것)

- 손글씨 인식: MyScript의 유료 엔진이 하는 일이다(D-222).
- 음원 라이브러리: 원본이 소유한 녹음.
- 기타 지판·드럼 패드·TAB·하프 주법: 피아노 앱 범위 밖.
- 원본의 아이콘·화면 그림·문구: 쓰지 않는다. 아이콘은 우리가 넣은 Bravura 악보 글꼴 기호, 문구는 우리 것.
- 계정·구독·기기 간 전송.

## Size

화면 8, 흐름 7. 남은 것(`parity.md`의 Missing)은 크게 세 부류다.
- 새 장치·엔진이 필요한 것: MIDI 건반 입력, 실시간 녹음 입력, 믹서, 보기 방식 전환(인쇄·이어 보기).
- 재생에서 고를 수 없는 것: 늘임표 길이, 스윙 세기, tacet.
- 드물게 쓰는 표기: 사분음, 겹온음표, 붙여넣기 다시 흘리기, 마디 번호 다시 매기기, 보표 묶음, 성부 색.

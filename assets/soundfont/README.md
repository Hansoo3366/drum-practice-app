# SoundFont for score playback

- File: `GeneralUser-GS.sf2` (GeneralUser GS v2.0.3 by S. Christian Collins)
- Source: <https://github.com/mrbumpy409/GeneralUser-GS>, <https://www.schristiancollins.com/generaluser>
- Licence: `GeneralUser-GS-LICENSE.txt` (free to use and to bundle in software;
  see its note on the origin of some samples before a commercial release)

Bundled with the piano flavor only. The app copies it to its support directory
on first use and plays scores through it (piano, organ, strings, pad, brass by
General MIDI program). Without the file, playback falls back to plain
waveforms.
